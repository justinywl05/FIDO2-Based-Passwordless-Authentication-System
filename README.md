# Nexus University Web Portal

An integrated web portal and management system developed as a Final Year Project (FYP). The platform streamlines campus operations, user authentication, and student/staff verification using dynamic QR code workflows.

---

## 📄 Project Documentation & Report

The comprehensive project documentation and written analysis have been published:
Final Year Project Written Report.pdf

---

## ✨ Key Features

- **Secure Authentication & Role Management**: Multi-tier authentication system for students, faculty, and administrators.
- **Dynamic QR Code Integration**: Fast, contact-free verification and attendance tracking via generated QR codes.
- **Student & Staff Portals**: Centralized dashboard to view schedules, profile details, and administrative updates.
- **RESTful API Backend**: Scalable backend architecture handling auth tokens, session validation, and database operations.

---

## 🛠️ Tech Stack

- **Backend**: ASP.NET Core (C#) / Web API
- **Frontend**: HTML5, CSS3, JavaScript / Modern Web Framework
- **Database**: SQL Server / Entity Framework Core
- **Authentication**: JWT / ASP.NET Identity
